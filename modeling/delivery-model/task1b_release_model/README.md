# Task 1B Release Model Code

This module provides release-curve analysis, recovery correction, quality checks, candidate screening, synthetic regression scenarios, and workbook construction.

`config.json` is an unfilled analysis configuration: validation flags are false and decision thresholds are null until the team records approved experimental criteria. Files under `data/templates/` are blank recording templates rather than experimental observations.

The generated `demo/` and `outputs/` directories are excluded from this GitHub source package. Synthetic results must not be presented as measured data or experimental validation.

Run the analysis with a reviewed configuration and matching GitLab data release.
