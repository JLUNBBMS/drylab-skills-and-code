# GitHub Upload Manifest

This package was curated for a Git repository that publishes skills and source code.

## Included

- Skill instructions, implementation scripts, references, tests, and required project metadata.
- Core Python model code, entry points, dependency lists, and external-data location notes.

## Excluded

- Member delivery archives and generated bytecode caches.
- Word and PDF reports, Wiki manuscripts, and tutorial media outside the skill itself.
- Raw or processed project datasets, fitted parameters, numerical result tables, generated model figures, and rendered reports.
- Publisher PDFs and other third-party research documents.

The excluded data and model results are intended for the team's GitLab data repository.
